# Release status

Checked 27 October 2026. Build dates below describe build records, not public release dates.

## Website

[focus.zynoks.com](https://focus.zynoks.com/) is available. The live site was checked for the timer, task creation and selection, timer recovery after reload, offline-download controls, and the mobile sound drawer. The website has no user-facing semantic version to map to an Android APK.

The current workspace includes original soundscapes, tasks/projects, session support and reviews, weekly summaries, local export/restore, and optional offline preparation. The README lists current functionality. Saved video links open YouTube externally; embedded playback and live search remain disabled.

## Android 1.0.1 / build 3

An internal cloud preview APK finished building on 14 October 2026. It identifies as **Zyn Focus**, package **app.zynfocus.mobile**, minimum Android **8.0 / API 26**, target API **36**, with ARM64, ARMv7, x86, and x86_64 libraries.

The downloaded artifact's package, version, cryptographic signature, archive integrity, and 16 KB ZIP alignment were checked. Its signing certificate matches the preceding cloud preview. Those checks do not establish physical-device behavior or public distribution approval. This exact APK has not received a new device/runtime test during repository preparation. No public download or GitHub release is provided here.

The current Android implementation includes local tasks, focus tools, reviews, backups, original audio, and Android-specific alarms, background media controls, and a widget. Source validation and earlier emulator checks are distinct from validating every feature in this APK. Full physical-device checks and release/rights review remain incomplete.

## Older previews

Internal Android 1.0.0 cloud previews and local review APKs also exist. They are not the current build and are not offered as the latest download. The earlier local APKs use a different signing key from cloud previews. Do not uninstall an existing installation without exporting a backup first.

## Other platforms and future work

No verified native desktop or iOS distributable, public store listing, or automatic Android update feed is available. Browser installation is separate from a native release. Embedded YouTube support is not enabled. No release date is promised for these items.
