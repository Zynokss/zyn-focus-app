# Backup, restore, and uninstall

Zyn Focus keeps your workspace in the browser profile or app installation you use. There is no account recovery or cloud sync. Browser storage and exported files are not encrypted by Zyn Focus. Backups may contain private task names, targets, reflections, and notes. Store them somewhere you trust and do not attach them to a public issue.

## Website export

1. Open the website in the browser profile that holds your work.
2. Go to [Privacy → Your local data controls](https://focus.zynoks.com/privacy#controls). Settings also links to **Export or clear local data**.
3. Use **Download local data** and keep the downloaded JSON file.

The export only contains this website address and browser profile's Zyn Focus data. It is not a backup of another browser or the Android app. Keep a second copy if the data matters to you.

## Website restore

1. Export the current workspace first if you may want to return to it.
2. On the same privacy page, use **Choose website backup** under **Restore a website backup**.
3. Review the preview. Restore replaces the current workspace; it does not merge two workspaces.
4. Choose **Confirm replace with backup** only when the preview is correct.

Restored timers are paused. Audio does not start automatically. Saved permission choices for optional YouTube connections are not imported. An invalid file is rejected. If storage fails, the website attempts to restore the previous workspace and reports failures. Keep the original export until you have checked the restored work.

## Android preview backup

For existing preview users, open **Space → Backup & restore**. Use **Export / share backup** or **Save backup to a folder**. Chosen recipients or storage services may keep or upload the file. The app removes its temporary sharing copies; exported copies remain under your control.

To restore, use **Choose backup to restore**, review the counts, choose **Replace with this backup**, and confirm. The current app workspace is replaced. A running session is exported paused and restored audio stays silent. Check your work afterward.

Website and Android backup formats are separate. A backup from one cannot be restored into the other. These instructions do not announce a public Android release.

## Clearing data

The website privacy page offers **Clear local data** followed by **Confirm clear local data**. Export first. It removes the current browser's Zyn Focus workspace and reloads other open Zyn Focus tabs. It does not erase downloaded backups, other devices, support email, or hosting logs.

Android's **Space → Settings → Data, privacy & legal** contains the local-data erase controls. Clearing app data in Android settings also removes the local workspace. Device permissions are managed separately in Android settings.

## Uninstalling

- **Browser app:** export first, then remove the installed web app using your browser or operating system. Removal may leave website data behind, depending on the browser. To erase it, use the website's clear-data control and, if needed, clear this site's storage and offline cache in browser settings. This removes the prepared offline copy too.
- **Android preview:** export to a location outside app storage, then uninstall through Android settings. App-local data is removed. Android cloud app backup is disabled in the inspected preview; do not rely on it for recovery.
- **Exported files:** deleting the app or website data does not delete files you saved elsewhere. Remove those separately if you no longer want them.
