# Frequently asked questions

## Do I need an account?

No. The workspace saves locally in your current browser profile or app installation.

## Does my work sync between devices?

No. There is no cloud sync or server task backup. Website and Android data are separate, and their backup formats are not interchangeable.

## Can I work offline?

The website can prepare its workspace, scenery, and original sounds through **Settings → Offline & install**. Download while connected and test before relying on it. The internal Android app bundles its core assets. External pages and YouTube still need internet.

## Where do I download Android, desktop, or iOS?

There is no approved public Android installer here yet. Android 1.0.1 / build 3 exists as an internal preview. No native Windows, Linux, macOS, or iOS release is verified. Use [the website](https://focus.zynoks.com/) and optional browser installation where supported. See [release status](../RELEASES.md).

## Is YouTube available inside the timer?

Embedded playback and live search are unavailable in the current product. You can save links and open them on YouTube externally. Original ambient soundscapes work independently of YouTube.

## Does a closed browser keep ringing?

No closed-page alert is promised. Browser alerts need an open page, and the operating system or browser can suspend it. Returning to the workspace reconciles the saved deadline. Android preview alarms are separate native features and still need physical-device testing.

## Are my notes encrypted?

Zyn Focus does not encrypt local workspace storage or exported backup files. Local storage avoids a task-upload service, but it is not an encrypted vault. Your device, browser, backup destination, hosting requests, and support messages have their own privacy considerations. See the [privacy policy](https://focus.zynoks.com/privacy).

## Can I restore a backup without losing today's work?

Restore replaces rather than merges the workspace. Export today's work first, preview the chosen backup, and confirm only when ready. Keep both exports until you have checked the result.

## Is this repository the app source?

No. It contains product documentation, pictures, and support templates. The application source is maintained separately. No open-source license to the application is granted here.
