# Product image provenance

| File | Type and origin | What it shows |
| --- | --- | --- |
| `images/zyn-focus-cover.webp` | Generated promotional artwork, built-in image-generation tool | A landscape and product message inspired by the real midnight/violet design. It does not depict an application screen. |
| `images/workspace-desktop.webp` | Actual live website capture, 27 October 2026 | Fresh 1440 × 960 browser viewport, default scene, idle timer, empty local workspace. |
| `images/soundscapes-mobile.webp` | Actual live website capture, 27 October 2026 | Fresh 390 × 844 CSS-pixel browser viewport at 2× scale, sound drawer. This is the mobile website, not the Android app. |

Screenshots were captured from https://focus.zynoks.com/ using separate, temporary browser contexts. No existing browser profile or personal app data was used. Images were converted to WebP to reduce download size; the interface was not reconstructed or redesigned. No synthetic sessions, histories, or performance figures are shown.

The cover uses the live workspace capture as a visual reference and the product's approved wordmark as a brand reference. [The full generation prompt](prompts/cover.md) records the distinction. Product scenery comes from the project's generated mountain artwork. Font and icon credits are in [rights and credits](../RIGHTS.md).
